# Guia de publicação no GitHub

O projeto está preparado em `public-release` e inclui `Iniciar GameNext.bat`. O BAT instala as dependências e baixa runtime e modelos quando executado pela primeira vez.

## Campos de publicação

**Título do commit:**

```text
Publica versão inicial do GameNext
```

**Descrição:**

```text
Adiciona o código-fonte e o inicializador para Windows. Na primeira execução, o BAT instala dependências e baixa runtime e modelos automaticamente.
```

O repositório de destino é `exestruturas-glitch/Chat-gamenext`. O commit inclui somente o código, documentação e scripts de inicialização; modelos, runtime e dados locais estão excluídos pelo `.gitignore`.
